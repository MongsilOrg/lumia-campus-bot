# lumia-bot

루미아 캠퍼스 커뮤니티 Discord 서버의 회원·포인트·상품 교환을 운영하는 봇. 포인트를 관리하고 포인트로 상품(쿠폰)을 구매·발급하며 이력과 재고를 추적한다.

## 주요 기능

- 포인트 적립·차감·조회·설정 (잔액 음수 차단)
- 회원 등록·삭제 (이메일 검증, 구매 이력 있으면 삭제 불가)
- 상품 등록·삭제·구매, 쿠폰 코드 발급, 중복 구매 방지
- 구매 이력·상품별 구매자 조회 (페이지네이션)
- 닉네임 변경
- 채널 상주 교환소 대시보드 (지정 역할만 구매)

## 동작 방식

슬래시 명령 → repository → Supabase 순으로 흐른다. 포인트 증감·구매·닉변처럼 정합성이 필요한 작업은 Supabase RPC로 처리한다. 재고는 `store` 테이블의 미할당 쿠폰 수로 계산하고, 구매 시 쿠폰 1건을 구매자에게 할당하며 포인트를 차감한다.

## 기술 스택

Python, discord.py(LayoutView), Supabase. PM2로 NAS 상시 구동.

## 제약

대부분 명령은 관리자 전용. 단일 길드 동기화(다중 서버 대상 아님).
