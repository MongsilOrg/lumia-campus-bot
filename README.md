# lumia-campus-bot

루미아 캠퍼스 Discord 서버의 포인트와 상품 교환을 운영하는 봇입니다.\
회원별 포인트를 관리하고, 포인트로 상품을 사면 쿠폰 코드를 발급합니다.

## 기능

- 교환소 대시보드: 지정 채널에 올려 둔 메시지 하나로 상품 목록과 재고, 품절을 보여 줌.\
  버튼으로 포인트 조회, 상품 구매, 구매 내역 확인.\
  구매는 학생회, 학부생, 재학생, 신입생 역할만 가능
- `/포인트`: 내 포인트 확인
- `/상품_구매`: 상품 이름을 넣어 구매하고 쿠폰 코드를 받음
- `/포인트_조회` `/포인트_추가` `/포인트_감소` `/포인트_업데이트`: 포인트 관리.\
  잔액이 음수가 되는 변경은 막음
- `/유저_정보등록` `/유저_정보삭제`: 회원 등록과 삭제.\
  이메일 형식을 검사하고, 구매 내역이 있으면 삭제할 수 없음
- `/상품_조회` `/상품_추가` `/상품_삭제`: 상품 관리
- `/쿠폰_추출`: 아직 할당되지 않은 쿠폰 코드 1건 추출
- `/구매이력` `/구매이력_조회` `/상품별_이력조회`: 구매 내역을 페이지 단위로 조회
- `/닉변`: 서버 닉네임 변경과 DB 반영

대시보드와 `/포인트`, `/상품_구매`를 뺀 명령은 관리자만 씁니다.

## 동작 방식

슬래시 명령과 대시보드 버튼은 repository 계층을 거쳐 Supabase를 부릅니다.\
포인트 증감, 구매, 쿠폰 추출, 닉변은 Supabase RPC로 DB 함수 하나에서 처리해 포인트 차감과 쿠폰 할당 가운데 한쪽만 반영되는 일이 없습니다.\
재고는 `store` 테이블에서 아직 할당되지 않은 쿠폰 수로 계산하고, 구매하면 쿠폰 1건을 구매자에게 할당하고 포인트를 차감합니다.

## 실행

```bash
pip install -r requirements.txt
# .env 파일을 만들고 아래 설정 키를 채움
python main.py
```

## 설정

| 키 | 설명 |
|---|---|
| BOT_TOKEN | Discord 봇 토큰 |
| GUILD_ID | 명령을 동기화할 서버 ID |
| DASHBOARD_CHANNEL_ID | 교환소 대시보드를 띄울 채널 ID |
| SUPABASE_URL | Supabase 프로젝트 URL |
| SUPABASE_KEY | Supabase API 키 |
| SENTRY_DSN | Sentry DSN.<br>비우면 에러 수집 비활성 |
