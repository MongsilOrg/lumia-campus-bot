# lumia-campus-bot

루미아 캠퍼스 Discord 서버의 포인트와 상품 교환을 운영하는 봇. 회원별 포인트를 관리하고, 포인트로 상품을 구매하면 쿠폰 코드를 발급한다.

## 기능

- 교환소 대시보드: 지정 채널에 상주하며 상품 목록과 재고, 품절을 표시한다. 버튼으로 포인트 조회, 상품 구매, 구매내역 확인. 구매는 학생회, 학부생, 재학생, 신입생 역할만 가능
- `/포인트`: 내 포인트 확인
- `/상품_구매`: 상품 이름을 입력해 구매하고 쿠폰 코드를 받는다
- `/포인트_조회` `/포인트_추가` `/포인트_감소` `/포인트_업데이트`: 포인트 관리. 잔액 음수 차단
- `/유저_정보등록` `/유저_정보삭제`: 회원 등록과 삭제. 이메일 형식 검증, 구매 이력이 있으면 삭제 불가
- `/상품_조회` `/상품_추가` `/상품_삭제`: 상품 관리
- `/쿠폰_추출`: 미할당 쿠폰 코드 1건 추출
- `/구매이력` `/구매이력_조회` `/상품별_이력조회`: 구매 이력을 페이지 단위로 조회
- `/닉변`: 서버 닉네임 변경과 DB 반영

대시보드와 `/포인트`, `/상품_구매`를 제외한 명령은 관리자 전용이다.

## 동작 방식

슬래시 명령과 대시보드 버튼이 repository 계층을 거쳐 Supabase를 호출한다. 포인트 증감, 구매, 쿠폰 추출, 닉변은 Supabase RPC로 처리해 정합성을 지킨다. 재고는 `store` 테이블의 미할당 쿠폰 수로 계산하고, 구매하면 쿠폰 1건을 구매자에게 할당하며 포인트를 차감한다.

## 실행

```bash
pip install -r requirements.txt sentry-sdk

# .env 파일을 만들고 아래 설정 키를 채운다
python main.py
```

## 설정

| 키 | 설명 |
|---|---|
| BOT_TOKEN | Discord 봇 토큰 |
| GUILD_ID | 명령을 동기화할 서버 ID |
| DASHBOARD_CHANNEL_ID | 교환소 대시보드를 띄울 채널 ID |
| SUPABASE_URL | Supabase 프로젝트 URL |
| SUPABASE_KEY | Supabase API 키 |
| SENTRY_DSN | Sentry DSN. 비우면 에러 수집 비활성 |
